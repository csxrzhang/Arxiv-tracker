OpenVLHarness: Real World Visual Agentic Tool-Use with Multimodal Memory
标题：OpenVLHarness：基于多模态记忆的真实世界视觉智能体工具使用
Authors: Yu Zhou, Cheng-Fu Yang, Rui Sun
类别：cs.CL · cs.AI · cs.CV · cs.LG · cs.MM，链接：Abs · PDF · Code1 · Code2

Reinforcement Learning with Visually Attributable On-Policy Self-Distillation
标题：基于视觉可归因同策略自蒸馏的强化学习
Authors: Shiao Xie, Siyu Chen, Jianwei Lv
类别：cs.CV · cs.AI，链接：Abs · PDF · Code1 · Code2
带可验证奖励的多模态强化学习（RLVR）提供了可靠的任务级监督，但对视觉推理中的错误定位指导有限。同策略自蒸馏（OPSD）通过来自具备以证据为中心视觉视角的特权教师的密集 token 级纠正来补充这种监督。然而，由此产生的纠正可能将视觉证据与由语言先验、回答风格或特权视角本身引起的非视觉偏移混为一谈。我们将这一现象形式化为特权纠正污染：当某个 token 级纠正的更新方向无法一致地归因于特权视觉证据时，该纠正即被污染。因此，直接蒸馏被污染的纠正可能会强化错误的 token 级更新。为解决这一问题，我们提出基于视觉可归因同策略自蒸馏的强化学习，这是一种证据一致的范式，用基于视觉证据的特权 token 级纠正来增强任务级 RLVR 监督。我们以视觉归因门控（VAG）实例化该范式，其使用验证器导出的优势作为优化锚点，并针对证据存在与证据退化教师视角之间的对比来验证每个特权纠正。通过仅接纳受该视觉对比方向性支持的纠正，VAG 在保留视觉 grounded 指导的同时抑制不一致的残差。在六个视觉推理基准上的实验表明，VAG 持续优于 GRPO 和 OPSD 方法，确立了新的最先进平均性能。

Train An Imaginative Agent

Authors: Jiaxin Ge, Junyi Zhang, Tianning Chai
类别：cs.AI，链接：Abs · PDF · Code1 · Code2
在推箱子（Sokoban）中，一个看似合理的推动可能使谜题变得无解。为避免此类错误，智能体必须在执行动作之前预判其后果，尤其是在真实环境反馈稀疏或动作不可逆的情况下。我们提出 Agentic Imagination（Agima），一个训练智能体在行动前进行想象的训练框架，即变得富有想象力。Agima 训练单个全能模型来提出动作、生成其结果的图像，然后对这些想象出的未来进行推理，以决定在真实环境中执行什么。智能体不必承诺于单一计划，而是可以模拟一系列动作、探索替代方案并比较可能的未来。我们首先使用监督微调（SFT）将策略与世界建模统一在单个全能模型中。这使智能体能够预测未来结果并执行基本形式的想象，例如前瞻思考和反事实分支。然后我们使用智能体强化学习（RL）教智能体对其想象的未来进行推理，并有效地将其用于规划。在涵盖 Maze2D、Sokoban、Pacman 和 PushT 的四个环境中，Agima 泛化到训练中未见过的更难设置。仅在双箱 Sokoban 上用 SFT 训练，Agima 解决了 40% 的四箱谜题，而每五步才看到一次真实棋盘，相比之下仅动作规划器只解决了 2%。经过 RL 后，Agima 使用其想象力的方式出现了新行为：它学习了一种在 SFT 阶段未见过的新的统一格式，学会了仅在必要时进行前瞻思考，并在关键决策点更频繁地分支。一个能够描绘其动作导向何处的智能体可以学会何时何地向前看，即进行规划。项目页面：https://agima.net/。
