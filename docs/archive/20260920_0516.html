Coding Agents with an Obstacle-Aware Harness for Safe Robot Manipulation
标题：面向安全机器人操作的障碍感知约束编码智能体
Authors: Bingxin Xu, Yuzhang Shang, Zhen Dong
类别：cs.RO · cs.AI · cs.CL · cs.CV，链接：Abs · PDF · Code1 · Code2
编码智能体已成为机器人操作的一种有前景的范式：语言模型将机器人控制器编写为程序，以这种方式构建的智能体如今无需机器人特定训练即可操作机器人。然而，这一范式是否同样安全尚未被探讨。我们在安全约束下评估编码智能体，其中每个任务将操作目标与机器人不得触碰的障碍物配对。智能体追求目标，但在大多数情况下会与障碍物碰撞，将任务完成视为唯一目标而忽视安全。智能体在其轨迹中对障碍物进行了推理，且提示中已禁止触碰它，因此既非感知也非指令有误；问题出在规划中，所述约束从未成为优先事项。通过将操作分解为路径阶段和接触密集时刻，我们定位了失败的根源。在路径上，模型无法优先考虑安全约束，既没有清空路径的概念，也没有在所选路径不可行时重新规划的概念。在接触时，它未意识到接触执行同样受该约束限制。为弥补这一差距，我们提出SafeHarness，为模型配备两个障碍感知约束，使其能够优先考虑安全约束。障碍感知路径规划将物体作为边界框进行定位，并在其上以路点序列绘制候选路径。智能体随后提前规划路径、验证路径、必要时重新规划，然后才执行。障碍感知接触执行则选择接触位置，使接触本身避开障碍物。SafeHarness达到71.9%的任务成功率和87.5%的碰撞避免率，分别超越此前SOTA 6.5%和27.0%。这些结果分别是同一智能体无约束时的2.3倍和1.5倍。

Authors: Nitish Dashora, Douglas Chen, Idan Shenfeld
Venue: CoRL 2026
类别：cs.RO · cs.AI，链接：Abs · PDF · Code1 · Code2
复杂的机器人操作任务通常需要对过去事件和动作的长期记忆。由于以完整历史为条件会使策略容易产生虚假关联并降低性能，许多策略记忆方法通过在循环中使用昂贵的VLM查询来压缩历史信息，以仅处理任务显著信息。在本文中，我们提出了一种替代方法，在训练时进行计算密集的VLM查询，以学习一种轻量级潜在记忆，可在部署时高效查询。我们的表示称为\textbf{工作空间令牌}，其训练方式是：(1) 使用VLM识别完成任务所需的当前和历史信息，然后 (2) 使用集合重建解码器损失将这些信息蒸馏到工作空间令牌中。在仿真和硬件中，我们表明工作空间令牌可在部署时直接替代观测，使策略无需在循环中进行VLM推理即可解决记忆密集型任务。有趣的是，我们发现工作空间令牌不仅更轻量，而且能带来更好的策略性能。

Venue: NeurIPS 2026

Quantifying Overclaiming Propensity in Frontier LLM Agents
标题：量化前沿LLM智能体的过度声称倾向
Authors: Nolan Smyth, Yorguin-Jose Mantilla-Ramos, Pascal Jr Tikeng Notsawo
类别：cs.SE · cs.AI · cs.LG，链接：Abs · PDF · Code1 · Code2

Score Centering Stabilizes Off-policy Reinforcement Learning
标题：分数中心化稳定离策略强化学习
Authors: Martin Marek, Max Ryabinin
类别：cs.LG，链接：Abs · PDF · Code1 · Code2
大型语言模型的强化学习（RL）对训练与推理引擎之间的微小差异极为敏感，这通常被称为训练-推理不匹配（TIM）。然而，完全消除TIM是不切实际的，因为这会对rollout效率造成重大代价。在本文中，我们表明TIM下RL的不稳定性主要由漂移引起：训练与推理引擎之间持续存在的偏差会随每个训练步骤累积。我们推导出一个加性的“分数中心化”校正项，通过抵消漂移来稳定TIM下的RL。在训练0.6B到30B参数的模型时，仅分数中心化就能匹配或优于量化下基于重要性采样的方法，且随着不匹配变得更严重，差距会扩大。由于该校正是加性的，分数中心化还可以与重要性采样组合——在我们的陈旧性实验中，它们的组合优于纯重要性采样基线。
An Empirical Study of Harness Design for Coding Agents
标题：面向编码智能体的执行框架设计的实证研究
Authors: Run-Ze Fan, Zihao Zhang, Simin Ma
类别：cs.AI · cs.CL · cs.LG · cs.SE，链接：Abs · PDF · Code1 · Code2
编码执行框架决定了自主编码智能体如何将模型能力转化为长时程软件工程表现，但现有工作通常将执行框架作为整体系统进行评估，导致各单独组件的有效性尚不明确。为实现组件级比较，我们用一个轻量级编码执行框架研究该问题，其执行循环固定，而变化三个组件：规划、动作空间和上下文管理。在 SWE-Bench Verified 和 Terminal-Bench 2.1 上对四个模型进行评估，我们评测了 176 个匹配设置，涵盖五种上下文管理策略、四种上下文窗口预算，以及对规划和动作空间的有针对性消融。我们发现：(1) 随着上下文窗口预算收紧，上下文管理变得愈发有价值，其大部分收益来自防止上下文溢出失败。(2) 在基于 LLM 的摘要之前先进行基于规则的省略，在上下文管理策略中总体效率最强，而让被省略内容可恢复则增加了模型很少使用的机制，且未带来准确率提升。(3) 规划从较弱模型的准确率支架转变为较强模型的成本节省手段，准确率变化很小。(4) 预定义工具可提升 bash 熟练度较弱模型的表现，而具备 bash 能力的模型可仅用 bash 接口有效运行，并实现显著更低的成本，尤其是在以命令行为中心的任务上。轨迹级分析解释了这些效应：上下文管理延长执行轨迹而不显著改变智能体行为，规划改变轨迹停止的位置，动作空间改变代码编写的粒度。这些发现为模型感知和预算感知的执行框架设计提供依据，并为评估未来执行框架组件提供了模块化框架。
