Beyond Naturalness: Probing Automated Text-To-Speech Evaluators on Linguistically Grounded Dimensions
标题：超越自然度：在语言学基础维度上探究自动文语转换评估器
Authors: Oluwanifemi Bamgbose, Simon Rosen, Jash Shah
类别：cs.SD · cs.AI · cs.CL，链接：Abs · PDF · Code1 · Code2
自动文语转换（TTS）评估方法（平均意见得分（MOS）预测器和音频大语言模型（Audio-LLM）评判器）应反映人类感知，但尚不清楚它们能在多大程度上捕捉听者实际感知的语音的不同方面。我们将“自然度”解构为一个基于语言学的标注模式，涵盖10个不同的感知维度，并以此构建首个针对TTS的维度级元评估基准，包含860条由训练有素的语言学家标注的语音。对四个MOS预测器和四个Audio-LLM评判器的基准测试结果显示，MOS预测器主要聚焦于声学信号质量，而Audio-LLM评判器表现出选择性、依赖提示的检测能力，且无法在所有维度上泛化。两类方法均不能可靠地捕捉广泛的语言结构化语音错误。我们的数据集、标注模式和评估代码已公开，以支持更具针对性和可解释性的TTS评估。
Multimodal Model Diffing for Feature Discovery and Control
标题：多模态模型差异分析用于特征发现与控制
Authors: Hunar Batra, Lachin Naghashyar, Ashkan Khakzar
Venue: ICML 2026
类别：cs.CV · cs.AI · cs.CL · cs.LG，链接：Abs · PDF · Code1 · Code2
多模态大语言模型（MLLMs）展现出强大的视觉理解能力，但导致这些行为的内部特征仍难以识别、审计或控制。虽然适用于事后检查，但使用稀疏自编码器（SAEs）分解为可解释特征方向的隐藏状态，既不能轻易隔离多模态训练改变了哪些特征，也不直接用于目标控制。我们引入MMDiff，一个多模态模型差异分析框架，训练多模态SAEs并将其转化为特征级接口，用于发现和控制多模态行为。MMDiff支持三种用途：（i）特征隔离，通过将基础LM SAE与其多模态适应版本进行差异分析，识别多模态训练改变的特征；（ii）任务特定特征检测，通过逐令牌对比激发分析隔离因果特征；（iii）特征级控制，通过因果移除或引导发现的特征方向。我们为三个MLLM家族（LLaVA-MORE、PaliGemma 2和InternVL3.5）训练多模态SAEs，并在视觉空间理解、多模态安全性和OCR上评估。MMDiff发现稀疏、因果特定的特征，其移除选择性地降低目标行为，在空间任务上平均降低12%，在OCR上降低17%，并将多模态安全攻击的成功率降低24%，且不影响VQA性能。引导这些特征在空间和OCR准确性上平均比标准单层引导基线提高+3.6%和+1.8%。这些结果表明，多模态SAEs不仅可作为可解释性工具，还可作为审计、引导和控制MLLMs行为的机制，以实现更安全、更强大的生成。

Authors: Laurens Samson, Iva Gornishka, Gossa Lô
类别：cs.CL · cs.AI，链接：Abs · PDF · Code1 · Code2

GENCO - A Unified Neural Solver Embedded in a Development Framework for Steady-State Grid Analysis
标题：GENCO - 一种嵌入开发框架中的统一神经求解器，用于稳态电网分析
Authors: Alban Puech, Matteo Mazzonelli, Tamara R. Govindasamy
类别：cs.AI，链接：Abs · PDF · Code1 · Code2
基础模型正在改变业务流程并提高生产力，但在电力系统分析等工程领域仍然基本缺席，这些领域必须强制执行严格的物理一致性。 我们提出了GENCO（几何神经校正优化器），一种用于稳态输电网分析的统一神经求解器，在单一架构和共享网络表示中处理潮流（PF）、最优潮流（OPF）和状态估计（SE）。为了支持神经电力系统求解器的进展，我们引入了开源GridFM开发框架，该框架在低代码环境中标准化合成数据生成和训练。我们还发布了大规模数据集，包含跨多种电网拓扑的数百万个PF和OPF场景，以支持可复现的基准测试。 我们在PFDelta和OPFData基准上评估了GENCO，与最先进的神经求解器和经典求解器（包括Newton-Raphson和IPOPT）以及真实世界的Hydro-Québec SCADA数据进行了比较。对于大规模PF，GENCO恢复了完整的交流运行状态，包括直流PF无法提供的电压幅值和无功功率，同时匹配直流PF级别的有功功率平衡残差。它比Newton-Raphson快达30倍，而运行时间仅为直流PF的2倍。对于OPF，它比IPOPT快达85倍，同时在可行性、最优性和运行时间上优于直流OPF。对于SE，GENCO比经典加权最小二乘法对噪声测量和网络参数误差更鲁棒，并且即使加权最小二乘法无法收敛，也总能返回高质量的估计。 总之，统一架构和开发框架为大规模稳态电网分析提供了一种新方法，降低了电力系统工程师的入门门槛，并朝着电网基础模型迈出了一步。

标题：链接预测中的公平性超越人口统计均等：一项可复现性研究
Authors: Valentijn Oldenburg, Floris de Kam, Stef de Wildt
Venue: Transactions on Machine Learning Research, 2026
类别：cs.LG · cs.SI，链接：Abs · PDF · Code1 · Code2 · Code3
在公平排序链接预测中，人口统计均等（$\Delta_\mathrm{DP}$）是常用的公平性指标。然而，Mattos等人（2025）认为该指标忽略了链接在排序中的位置，因此无法检测曝光偏差。在本研究中，我们通过展示即使某些子群对链接系统性地排名低于其他链接，$\Delta_\mathrm{DP}$仍可能显示总体均等，从而复现了这一论断。而所提出的排序感知归一化折扣KL散度（NDKL）则能检测到此类差异。我们还复现了MORAL的有效性，这是一种后处理方法，在保持竞争性效用的同时改善基于曝光的公平性。在复现之外，我们通过合成同质性设置、分类敏感属性以及额外的公平性和效用指标（包括子群对适应的注意力加权排序公平性（AWRF））来评估鲁棒性。总体而言，我们的结果表明，基于曝光的指标能揭示$\Delta_\mathrm{DP}$隐藏的偏差，且MORAL在多种设置和数据集上以极小的效用损失减少这些偏差。我们在https://github.com/Floris93100/reproducing-MORAL发布了修正后的可复现实现。
