GameHorizon Suite: Multi-Horizon Data and Evaluation in Gameplay
标题：GameHorizon Suite：游戏玩法中的多时间跨度数据与评估
Authors: Yiran Wang, Xingyilang Yin, Junfu Pu
类别：cs.CV · cs.AI，链接：Abs · PDF · Code1 · Code2 · Code3 · Project1
现代视频游戏为AI模型提供了一个可测量的测试平台，结合了视觉理解、指令分解、目标规划以及在多个时间跨度上的精确动作控制能力。然而，现有数据集和基准要么覆盖的游戏范围狭窄，要么缺乏语言指令，要么依赖高方差的在线推演。为解决这些挑战，我们提出了GameHorizon，一个统一的数据与评估套件，用于衡量不同模型家族在不同时间跨度上的游戏玩法能力。GameHorizon Suite包含三个组件。第一，GameHorizon-Annotator是一个可扩展且自动化的多时间跨度指令标注流水线。第二，利用该流水线，我们构建了GameHorizon-Data，这是首个大规模AAA游戏玩法数据集，包含时间对齐的视频、玩家动作和多时间跨度指令。它包含来自21款游戏的5,000小时录制数据，由100名人类专家玩家采集。第三，我们构建了GameHorizon-Bench，具有可复现的离线和逐步在线测试。离线赛道使用数千个标准化问题实现可复现评估，这些问题组织为三个主要任务和一系列诊断变体；在线赛道测试离线分数是否反映实际游戏玩法能力，并将失败定位到长时程游戏玩法中的特定步骤。基于我们的GameHorizon Suite，我们通过超过一百万次模型调用评估了47个模型，揭示了任务难度的有意义的层级以及模型能力之间的显著差异。我们的工作可以为评估跨时间跨度和模型家族的游戏玩法能力提供标准化标尺。我们将发布数据集、标注器和基准以促进未来研究。
Critical-State RL: Diagnosing Trainable States for Multi-Turn Tool Use
标题：临界状态强化学习：诊断多轮工具使用中的可训练状态
Authors: Zixiang Chen, Wenting Zhao, Zhepeng Cen
类别：cs.LG · cs.CL，链接：Abs · PDF · Code1 · Code2
多轮工具使用的失败可能取决于单次模型调用，但仅凭奖励变化无法揭示哪次调用能从训练中受益。当奖励依赖于后续交互时，其变化可能反映下游随机性，而非当前动作之间的差异。我们提出临界状态强化学习，以识别多轮交互中的可训练状态。给定任务定义的候选调用和局部奖励，该方法评估每个奖励是否捕捉到动作对任务成功的影响，以及是否可能相对于参考策略有所改进。然后使用嵌套采样将动作相关的奖励变化与延续噪声分离，并在所选状态上使用上下文赌博机训练优化策略。在伯克利函数调用排行榜（BFCL）v4上的实验比较了在诊断所选状态上的训练与在替代状态上的训练。对于缺失函数任务，诊断选择工具可用后的响应；对于缺失参数任务，它选择在提供缺失参数之前的响应。训练所选响应可提升性能，包括在缺失函数任务上约14个百分点，而训练替代响应则使性能持平或更差。我们进一步将该方法应用于不同模型和任务，包括记录重复调用避免和内存管理。
WorldCrafter: Consistent Video World Model with Implicit 3D-aware Memory

Authors: Wangbo Yu, Kunhao Liu, Wenbo Hu
类别：cs.CV · cs.AI · cs.GR，链接：Abs · PDF · Code1 · Code2 · Project1
视频世界模型能够实现对动态环境的交互式探索，但难以在长时程和跨视角下保持对先前观测的一致性。我们提出WorldCrafter，一种视频世界模型，为此学习了一个可相机查询的隐式3D感知记忆。其核心思想是让请求的视角决定多视角证据如何被压缩到视频生成器有限的token预算中。通过与视频生成器联合训练，记忆编码器和姿态条件读出模块在去噪前将历史观测整合为一组固定的目标视角特定token，无需显式的基于深度的对应关系。通过将此记忆与近期时间上下文和少步蒸馏相结合，WorldCrafter能够从单张输入图像或文本提示实现流式场景探索。在静态和动态场景上的实验表明，在分钟级探索过程中，长时程一致性和相机控制精度均有显著提升，同时保持了视觉质量。

Authors: Lei Yang, Mengyin Liu, Jia Wang
类别：cs.CL · cs.HC · cs.LG，链接：Abs · PDF · Code1 · Code2 · Project1
我们提出onPanda，一个用于高效标注LLM对齐数据和智能体轨迹的交互式工具。onPanda以词元级校正为核心交互方式：在阅读模型回复时，标注者定位第一个不合适的词元，并从模型的候选词元中选择替代项，或通过自由形式编辑输入正确文本。系统随后截断该位置之后的所有内容，并从校正后的前缀继续生成，重复这一“定位—校正—继续”循环，直到获得满意的回复。该机制让标注者能够以低成本精确引导模型输出：一项小规模对照研究表明，onPanda相比人工后期编辑将标注时间中位数减少了52%。由于最终回复中的绝大多数词元由模型自身生成，所得数据在很大程度上保留了模型的采样分布，非常适合构建同策略SFT和偏好数据。此外，标注过程中记录的词元级校正提供了具有精确位置的细粒度监督，并自然形成正负样本对。onPanda还可连接外部工具和运行框架，从而在真实环境中进行交互式轨迹标注。此外，我们发布了使用onPanda标注的数据集Panda-CVL，以及一个词元级校正基准。
LoRA-generating hypernetworks for efficient on-device LLM generative personalization
标题：用于高效设备端LLM生成式个性化的LoRA生成超网络
Authors: Sean Augenstein, Li Ding, Jihwan Lee
类别：cs.LG，链接：Abs · PDF · Code1 · Code2
设备端大语言模型（`LLM'），例如在手机上运行的模型，非常适合通过个性化来改进。移动设备的有限计算资源限制了模型规模和模型质量，因此任何可实现的质量提升都具有重大影响。同时，其个人性质（即与特定用户的紧密耦合）意味着给定的设备端LLM往往会随时间以相似、可预测的模式被使用。本文提出了一种个性化设备端LLM的新方法。它训练一个超网络，将用户的上下文token映射到适合该用户的低秩适配（`LoRA'）。一旦训练好的通用工件部署到用户设备上，每个用户就使用该超网络（完全在设备上）合成个性化的LoRA。这种方法融合了LLM定制两种现有方法——上下文学习（`ICL'）和参数高效微调（`PEFT'）——的优点，同时避免了它们的缺点。与ICL一样（且不同于PEFT），我们方法的设备端阶段在计算上可行，只需要通过神经网络进行前向传播。与PEFT一样（且不同于ICL），我们的方法通过权重（LoRA）修改`目标'基础LLM，避免了与扩展输入序列相关的负面后果（例如延迟增加）。我们的方法特别适合移动设备场景。除了提到的设备端计算和延迟优势外，它还需要最少的额外存储，因为其架构内部部分利用了属于待个性化目标LLM的相同LLM权重。我们在几个具有代表性的个性化数据集上展示了LoRA生成超网络的优点，并与ICL和PEFT等基线进行了比较。值得注意的是，我们的个性化实验侧重于更具挑战性且研究较少的长文本生成任务。
DexTacWAM: A Visuo-Tactile World-Action Model for Dexterous Manipulation
标题：DexTacWAM：面向灵巧操作的视触觉世界-动作模型
Authors: Haoran Yuan, Zekai Wang, Boning Shao
类别：cs.RO · cs.AI · cs.CV，链接：Abs · PDF · Code1 · Code2 · Project1
灵巧操作依赖于接触动力学，而视觉往往只能部分观测到这些动力学。近期的世界-动作模型（WAM）将预测性视频世界建模与动作生成相结合，但大多仍以视觉为中心，因此无法直接建模这些接触动力学。我们提出 DexTacWAM，一种视触觉 WAM，它独立编码每个指尖，通过手指与位姿感知的触觉压缩器聚合所得特征，并将触觉潜变量注入视频扩散世界模型，以进行联合视触觉世界建模。在 22 自由度双臂平台的六个富接触灵巧操作任务中，DexTacWAM 在每个任务上均取得最高分，平均为 70.6，而最强基线为 38.0。消融实验将增益归因于将接触演化建模为预测世界状态的一部分，而非仅依赖触觉条件：在保持相同触觉特征和动作专家的情况下，移除触觉世界建模使四任务均值从 74.7 降至 26.6。在使用冻结的预训练视觉 VAE 进行四小时触觉编码器适配后，我们的持续视觉到触觉学习将预训练视频模型扩展到触觉，每个任务约需 100 个演示，且无需触觉中期训练，同时将视觉预测质量保持在仅视觉对应模型 0.5 dB 以内。该压缩器保留了融合前 89.4% 的接触召回率，同时实现 2.26 倍更快的训练和 1.29 倍更快的推理。总之，这些结果表明，预训练视频先验可以以数据和计算高效的方式扩展到分布式多指接触动力学。
Harness-Zero: Harness Distillation via Agent-as-Harness
标题：Harness-Zero：通过智能体即Harness的Harness蒸馏
Authors: Haoran Ye, Yuxing Lu, Haonan Dong
类别：cs.AI · cs.CL · cs.NE，链接：Abs · PDF · Code1 · Code2
Agent harness是介导模型与环境交互的外部系统，能显著提升智能体性能，但其收益在部署时仍与harness绑定。由于最佳harness因领域、实例和模型而异，通用智能体要么接受次优的共享harness，要么在日益增多的专用harness之间进行路由。因此，我们研究agent harness蒸馏：使用针对领域或实例优化的harness作为训练时指导，并将其诱导的行为迁移到模型权重中，使收益在单一固定目标harness下依然保留。挑战在于两个harness在动作空间和可用信息上不同，因此优化harness的指导不能直接作为目标harness的监督。我们提出Harness-Zero，通过agent-as-harness实现harness蒸馏。在优化harness的指导下，一个harnessing agent在目标harness的动作空间中执行前修正学生响应，将harness指导转化为训练示范。对所得轨迹进行微调，将harness诱导的行为内化到模型中，从而在部署时可移除专用harness。我们在知识工作、工具使用和科学领域的实验表明：(1) 对于使用同一演化harness的前沿LLM，agent-as-harness优于code-as-harness。(2) 在部署时移除专用harness后，Harness-Zero将基础模型的宏平均任务成功率从23.3%提升至44.3%，甚至超过仍挂载该harness时达到的41.7%。(3) Harness-Zero恢复了基础模型中缺失的harness诱导行为，在三个领域的28种模式中平均恢复率为82.3%。
