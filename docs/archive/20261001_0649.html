STEPQuant: When and Where Errors Matter in Delta-Rule Recurrent State Quantization
标题：STEPQuant：Delta规则循环状态量化中误差何时何地重要

类别：cs.CL · cs.AI · cs.LG，链接：Abs · PDF · Code1 · Code2 · Code3

LeapQuant: Efficient Linear Attention with Accurate Recurrent State Quantization
标题：LeapQuant：高效线性注意力与精确循环状态量化

类别：cs.LG · cs.AI，链接：Abs · PDF · Code1 · Code2

标题：LLM图重建中失真的谱理论：紧界与经验刻画
Authors: Jianru Shen
类别：cs.LG · cs.DM，链接：Abs · PDF · Code1 · Code2
