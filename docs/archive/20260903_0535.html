Beyond Scores: Understanding LLM-as-a-Judge Mechanisms in Summarization Evaluation
标题：超越分数：理解LLM作为评判者在摘要评估中的机制
Authors: Himil Vasava, Ming Jiang
Venue: EMNLP 2026
类别：cs.CL · cs.LG，链接：Abs · PDF · Code1 · Code2 · Code3
基于LLM的自然语言生成（NLG）质量评估器被广泛用作评分工具和自动化训练信号，但其分配评分的内部过程仍鲜为人知。我们通过一个八攻击扰动分类法（涵盖NLG质量的可读性和充分性维度）、一个生成管道（生成配对的干净和损坏摘要，具有受控错误强度和显式令牌级修改映射），以及一个四项实验组合（因果追踪、logit-lens词汇投影和注意力头消融），对Themis（Llama-3-8B）和Prometheus（Mistral-7B）进行了机制性研究。两个评估器都实现了一个结构化、连贯的评估管道，分两个阶段运行：在第15层以下，注意力执行局部错误比较并将结果路由到最终输入位置；在第15层以上，MLP级联整合信号并写入评分，决策在残差流中于一个尖锐的后期层（Themis上L=26，Prometheus上L=25）结晶。此外，同规模的基础模型对照（Llama-3-8B）重现了路由架构和结晶，但没有阶段分离，隔离了微调专门安装的两种机制：在最后位置抑制低于L15的MLP贡献，以及结晶深度提前两层，表明微调塑造了现有基底而非从头构建管道。我们在https://github.com/himil-v/judge-mech发布源代码和数据。

Adaptive Critical Token-Aware Retrieval for Repository-Level Code Generation
标题：面向仓库级代码生成的适应性关键令牌感知检索
Authors: Kefeng Duan, Dewu Zheng, Yanlin Wang
类别：cs.SE · cs.AI · cs.CL，链接：Abs · PDF · Code1 · Code2 · Code3
仓库级代码生成任务要求合成满足任务需求且与目标仓库上下文保持一致的代码。由于现实中的仓库通常超过大语言模型的输入长度限制，现有方法普遍采用检索增强生成（RAG）来提供仓库特定的上下文。尽管改进了仓库上下文的检索，现有方法通常将上下文作为任务级支持提供，而未明确识别在生成过程中需要细粒度仓库上下文的关键令牌。在大语言模型的自回归生成过程中，错误往往集中在少数决定性位置：一旦这些令牌生成错误，后续代码可能沿错误的语义路径发展，最终导致功能失败。我们将这些位置称为“关键令牌”。在本文中，我们提出ACToR，一种用于仓库级代码生成的适应性关键令牌感知检索框架。ACToR在生成过程中识别关键令牌，并按需触发针对性检索，以在这些决定性位置提供仓库上下文。此外，我们设计了一种位置感知加权方法用于密集检索器，以优先考虑对生成更具信息量的上下文。我们在两个代表性的仓库级基准RepoExec和CoderEval上评估了ACToR。实验结果表明，ACToR持续优于最先进的方法，在RepoExec上相对提升8.4%，在CoderEval上相对提升15.4%。除性能提升外，我们系统量化了关键令牌的影响，揭示其在主要生成失败中的核心作用，并强调针对性检索策略的必要性。我们在https://github.com/DeepSoftwareAnalytics/ACToR提供代码和数据。
Shallower ReLU Network Representations via Exact Linear Algebra
标题：通过精确线性代数实现的更浅ReLU网络表示
Authors: Kilian Rueß, Gennadiy Averkov, Florestan Brunck
类别：cs.LG · cs.NE，链接：Abs · PDF · Code1 · Code2
我们研究ReLU网络精确表示分段线性函数所需的深度，特别关注最大值函数。这个问题最近在机器学习和理论计算机科学文献中受到了广泛关注。我们证明对于每个$n\leq 12$，$\max_n(x)=\max\{x_1,\ldots,x_n\}$可以用两个隐藏层精确表示。此前，这一结果仅对$n\leq5$已知[Bakaev, Brunck, Hertrich, Stade, Yehudayoff, STOC'26]。我们通过候选解空间内的精确计算机辅助搜索获得构造：在对称性约化后，我们得到一个关于$\mathbb{Q}$上的有限线性方程组，使得任何解都能产生最大值函数的有效表示。所得构造具有结构化的第一隐藏层，这使其能够递归替换到更深的网络中。由此，我们得到$\max_n$的精确ReLU表示，其隐藏层数至多为$\lceil \log_6(n/2) \rceil+1$。因此，$\mathbb{R}^d$上的每个连续分段线性函数都可以用至多$\lceil\log_6((d+1)/2)\rceil+1$个隐藏层精确表示；特别地，对于$d\leq 11$，两个隐藏层就足够了。这些结果同样改进了[Bakaev, Brunck, Hertrich, Stade, Yehudayoff, STOC'26]，他们证明了以三为底的对数界。
